# 传播链条定价体系

> 来源：《药神体系全景分析》2026-09-19（碎碎念行号可溯源）。这是 20260919 深读确认的核心增量：传播链条不是外围观察，是他体系的显式组件。

## 定位修正：他不是"引导"预期，是"预测共识形成的路径"

他反复自称跟随者：

- "市场肯埋单的观点才是正确的观点"（行651）
- "跟随资金有明确卖出的时候看空，而不是提前几个月侃侃而谈"（行643）

他做的事是**站在传播链上游预判共识的扩散方向和速度**。

## 六个显式组件

1. **信息层级自检**："任何时候都应该评估自己接受到信息的时候处于传播的第几层级"（行15690，2021.3）
   - 第 3 层之后的信息，只在第 1-2 层仓位兑现时才有意义。
2. **传播=顶**："成交量排行大量出现同一个板块股票的时候就是板块见顶标志"（行7230）——后演化成"成交集中度45%见顶"规则（已在股票量化系统建库实测路径上）。
3. **共识进度计价**："基民仓位低的时候，机构讲什么故事都是真的；基民仓位高的时候，讲什么都是假的"（行31646）
4. **讲清楚即终局**："很多时候见顶不是因为贵贱，而是把市场讲清楚了……都是讲不清楚赚钱"（行25201）
5. **超额收益分解**："30%来自一致性情绪，50%来自估值提升，剩下20%来自价值本身"（2025.7.29）
6. **终极表述**："交易的本质，是释放市场的动物性……价值、利润、估值、产业研究，都是释放动物性凝聚一致性的手段"（2026.1.21，即 SKILL.md 模型3）

## 教科书案例：地产套利（买别人的预期行为）

他骂了两年房价却买地产股。推演链：卖方复苏研报全在风险提示里写"房地产超预期下跌"→ 宏观分析师必然被复苏叙事逼着集体看多 → 资金合力可预测 → "先上车……看到量能足了，市场接不住了，走人"（行32171）。

**他买的是别人的预期行为，不是基本面。** 为此做了两年微观功课：盯几十个中介抖音号、花钱进地产大V星球（行31543）——微观高频调研碾压二手研报，他的预期差全部来自一手观测，没有一条来自卖方报告。

## 配套工具

- **题材三问**："我买之后还能继续骗不？还能骗多久？"（行42595）
- **小烂标准**："热门板块；容易吸引关注度且去传播传销的股票……只有大家的注意力值钱"（行40514）

## 语境警告（勿混用）

筹码三问/题材传播博弈**只适用散户对手盘的小票题材语境**。股票量化系统小秘书实测：药神规则族在蓝筹池（机构对手盘）全部不适用，"放量突破追入"被四源收敛证伪——蓝筹语境"安静突破>放量突破"，量能与后续超额单调负相关。**两套市场结构，不可混用。**

## 与 SKILL.md 的关系

- 模型3（动物性与一致性）是本体系的哲学层；本文件是其操作层（层级自检、集中度信号、共识计价）。
