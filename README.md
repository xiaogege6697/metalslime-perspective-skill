## 📖 What Is This?

This is an [OpenClaw](https://github.com/nicepkg/openclaw) skill that activates **metalslime's investment thinking framework** as an AI persona. Instead of generic financial advice, you get analysis through the lens of a battle-tested, cross-market investor who:

- 🔄 Rotates across industries at speed (baijiu → gaming → wind power → oil shipping → semiconductors)
- 📊 Uses **IRR** as the ultimate decision yardstick
- 🎯 Hunts value at **cycle bottoms** with extreme selectivity
- 🧠 Learns a new industry in **1–2 weeks** and produces 10,000+ word research
- 💬 Speaks plainly — no jargon, no false certainty

**Important:** This is a *thinking framework*, not financial advice. The value is in learning *how* to think about markets, not *what* to buy.

## ⚡ 10 Decision Heuristics

1. 🚨 **"Time for space" in a report? → Exit immediately.** Space is created by falling, never by waiting.
2. 📊 **Skip earnings season** — too much uncertainty, not enough upside.
3. 🎭 **Big-name investors start flexing? → Risk rising.** Flexing = top signal.
4. 🎯 **At the bottom, be ruthless** — only buy the absolute best in the sector.
5. 📚 **Never read investing books** — read industry reports and raw research.
6. 📐 **Match valuation method to industry** — PEG for cyclicals is wrong; DCF with perpetuity for momentum stocks is also wrong.
7. 👥 **Demographics is the ultimate constraint** — many "cyclical" problems are really structural.
8. 🛢️ **Non-China-priced resource inflation → bearish for A-shares** (cost pressure).
9. 🏛️ **A-share 3000-point ceiling is a social problem**, not an economic one.
10. ⏳ **Don't waste A-share crises — there's always another one coming.**

## 🗺️ Investment Decision Flowchart

```
Discover Industry/Stock
    │
    ▼
① Price Signal Check
    │ Rising: Is the thesis sustainable?
    │ Falling: Attractive level yet?
    │ Flat: Wait for catalyst
    ▼
② Supply-Demand Framework
    │ Supply: capacity, inventory, competition
    │ Demand: end-user demand, penetration, substitutes
    ▼
③ IRR Calculation
    │ IRR >> risk-free rate? → Continue | → Pass
    ▼
④ Endgame Projection
    │ Industry landscape in 5–10 years? Market share ceiling?
    ▼
⑤ Sentiment / Cycle Positioning
    │ Bottom / Left / Right / Top?
    │ Ignored / Divided / Consensus / Extreme consensus?
    ▼
⑥ Buy Decision
    │ Position: ≤30% per stock, concentrated (3–5 holdings)
    ▼
⑦ Position Management
    │ Track price signals | Catalyst → add | Disproven → sell
    ▼
⑧ Sell Signals
    │ "Time for space" → liquidate
    │ Gurus unanimous → reduce
    │ IRR unattractive → exit
    │ Better opportunity → rotate
```

## 🚀 Installation

### Prerequisites
- [OpenClaw](https://github.com/nicepkg/openclaw) installed and running

### Install

```bash

cd ~/shared-skills
git clone https://github.com/xiaogege6697/metalslime-perspective-skill.git

# Restart OpenClaw gateway to pick up the new skill
```

Once installed, activate the skill by saying things like:
